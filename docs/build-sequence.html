How to read it

  • A chunk can start once every chunk in its needs line is merged.
  • Same column = safe to build in parallel (e.g. P2 · P4 · P6).
  • P7 waits on P5 (endpoints) and P6 (shell).
  • P8 waits on P4 (services) and P3 (data).
  • ◆ marks the critical path — the longest chain.

Critical path: P1 → P4 → P5 → P7 → P9 → P10. That chain sets the floor on wall-clock; the ingestion lane (P2→P3) and P6 have slack and feed in along the way. Your planned parallel start — P2 · P4 · P6 — is exactly stage 1.
